# Installed Skills

A verified selection from the *Build Your Whole Team with Claude* chart, vendored here as
ready-to-use Claude Code skills. Each folder contains a `SKILL.md` and is picked up
automatically by Claude Code from `.claude/skills/`.

See the full catalog in [`../../SKILLS.md`](../../SKILLS.md).
